|---|---|---|
| pytest, unittest, mocha | the runner itself dies (tests run in-process) | -11 / -6 / -9 direct; 139 behind `; exit $?` |
| jest, one test file | runs in band: jest dies, **both streams empty** | -11 / -6 / -9; 139 |

| cargo test | `(signal: 11, SIGSEGV: invalid memory reference)` | 101 |
| cargo nextest | `SIGSEGV [ … ]` status | 100 |
| ctest | `***Exception: SegFault`, `Subprocess aborted`, `Subprocess killed` | 8 |

Found while recording: Rust `raise(SIGSEGV)` from a test does nothing (std's SIGSEGV handler returns), a real fault was needed; PHP's `SIGSEGV` constant needs ext-pcntl (absent), so numeric signals were used; inside a container a process that is PID 1 ignores signals, so php needed `--init`.

### 4. Where the location is NOT extractable (or not where it should be)

- **googletest, uncaught exception**: `unknown file: Failure` / `C++ exception with description "not a number: x1" thrown in the test body.` No file, no line. Same for SetUp: `… thrown in SetUp().`
- **ctest, uncaught exception**: only `terminate called after throwing an instance of 'std::invalid_argument'` / `  what():  not a number: x1`, and only with `CTEST_OUTPUT_ON_FAILURE=1` or in `build/Testing/Temporary/LastTest.log`. Without the variable the console has no test output at all (`tests_failed` vs `tests_failed_output_on_failure`).
- **Catch2, exception**: the location printed is the `REQUIRE` line in the test (`…/tests/calc_test.cpp:6: FAILED:`), not the `throw` in `src/calc.cpp`; for a throwing fixture constructor it is the `TEST_CASE_METHOD` line (`…/calc_test.cpp:11: FAILED:`).
- **C++ link error**: `` calc_test.cpp:(.text+0x13): undefined reference to `mul(int, int)' ``: an object offset, no line.
- **vitest syntax error**: the position is wrong: `  File: …/test/calc.test.js:1:0` for a stray `)` on line 6.
- **gradle exception**: the console names the TEST frame `    java.lang.NumberFormatException at CalcTest.java:10`; the deepest project frame `\tat calc.Calc.parse(Calc.java:9)` is only in `build/test-results/test/TEST-calc.CalcTest.xml`. The assertion message is never on the console either (XML: `message="org.opentest4j.AssertionFailedError: expected: &lt;5&gt; but was: &lt;4&gt;"`).
- **gradle compile errors**: `/r/gradle/missing_target_symbol/src/test/java/calc/CalcTest.java:10: error: cannot find symbol`: line but no column (javac's caret line carries the column visually).
- **maven / gradle stack frames**: `\tat calc.Calc.parse(Calc.java:9)`: a file NAME, no directory; the path must be rebuilt from the package (`calc.Calc` → `src/main/java/calc/Calc.java`). Maven's summary `[ERROR]   CalcTest.parses:10 » NumberFormat …` gives the test line, not the deepest frame.
- **dotnet FailFast / access violation**: `   at Tests.CalcTests.Crashes()`: frames without `in file:line`.
- **jest + ts-jest**: the TS diagnostic position is wrapped in ANSI even without a TTY: `\x1b[96mtest/calc.test.ts\x1b[0m:\x1b[93m1\x1b[0m:\x1b[93m15\x1b[0m - \x1b[91merror\x1b[0m…` (strip `\x1b[…m` first). Pest's fatal banners likewise: `  at \x1b[32mtests/CalcTest.php\x1b[39m:\x1b[32m11\x1b[39m`.
- **jest setup_error**: location points into the `beforeAll` body but nothing marks it as setup.
- **node --test**: `  location: '…/test/calc.test.js:5:1'` is where the test is DEFINED; the failing line is in `stack:` (`    TestContext.<anonymous> (…/test/calc.test.js:6:10)`).
- **go**: `    calc_test.go:7: …` (t.Errorf) is a basename, ambiguous across packages; panic frames carry build-machine absolute paths (`\t/r/go-test/tests_failed_exception/calc.go:12`) and inlined frames print `(...)`. Compile errors are relative to the package dir: `./calc_test.go:6:12: undefined: Mul`, parse errors drop the `./`: `calc_test.go:8:4: expected '}', found 'EOF'`.
- **gcc** quotes identifiers with `‘…’` in a UTF-8 locale (`error: ‘mul’ was not declared in this scope`); ASCII quotes under LANG=C.
- **msbuild/VSTest** end some lines with CRLF (`MSBUILD : error MSB1001: Unknown switch.\r`, `   Test method Tests.CalcTests.Parses threw exception: \r`): anchor with `\r?$`.
- **docker runners**: every path is the container's (`/r/<runner>/<outcome>/…`), not the host's.
- **Rust**: the panic line gives the deepest `#[track_caller]` site (`panicked at src/calc.rs:6:22:`), here right; the full chain needs `RUST_BACKTRACE=1` (`   4: calc::calc::parse` / `             at ./src/calc.rs:6:22`).
